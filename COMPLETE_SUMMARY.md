## 🏗️ Firestore Database Schema

### Collection: `jobs`
```typescript
{
  id: string,              // Auto-generated by Firestore
  title: string,           // Job title (e.g., "Fix leaky faucet")
  description: string,     // Detailed job description
  startingPrice: number,   // Starting price for bids
  status: JobStatus,       // 'open' | 'accepted' | 'completed'
  createdAt: Timestamp     // Server-generated timestamp
}
```

### Collection: `bids`
```typescript
{
  id: string,              // Auto-generated by Firestore
  jobId: string,           // Reference to job document
  fixerId: string,         // Handyman/fixer user ID
  fixerName: string,       // Handyman/fixer display name
  amount: number,          // Bid amount in dollars
  message: string,         // Proposal/message from fixer
  createdAt: Timestamp     // Server-generated timestamp
}
```

## 🔒 Security Considerations

### Firestore Rules for Development
```javascript
// Use these rules for TESTING ONLY
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
```

### Firestore Rules for Production
```javascript
// Secure rules for production
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /jobs/{jobId} {
      allow read: if true;
      allow create: if request.auth != null;
      allow update, delete: if request.auth != null 
        && request.auth.uid == resource.data.userId;
    }
    
    match /bids/{bidId} {
      allow read: if true;
      allow create: if request.auth != null;
      allow update, delete: if request.auth != null 
        && request.auth.uid == resource.data.fixerId;
    }
  }
}
```
